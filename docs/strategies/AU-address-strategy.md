# AU 澳大利亚地址生成策略

| 项目 | 核心内容 |
|---|---|
| 主源 | Overture Maps addresses + Geofabrik Australia OSM 日更快照（可能含 G-NAF 来源标识） |
| 既有门牌级格式 / 邮编 | `<unit> <house> <street>, <suburb> <state> <postcode>, AU`；unit 缺失不补；源记录；格式门禁 4 位数字。只清洗格式，不创造或按邻近地址补齐 |
| 行政区 | ABS ASGS 作为候选核验；当前源字段与 catalog 反查。行政层级必须与坐标反查一致；冲突时保留源值在隔离区并拒绝发布 |
| 住宅子集证据 | 明确住宅建筑/用途证据；G-NAF 地址存在不等于住宅。住宅证据必须来自明确建筑/用途字段，不能由地址存在推断 |
| 真实字段 / 生成字段 | 门牌、道路、suburb、州代码、邮编、单元号和坐标均来自来源；生成字段：无，只执行可逆格式规范化 |
| 坐标 / 去重 | 来源坐标统一为 WGS84 并通过澳大利亚边界门禁；优先按稳定来源 ID，再按规范化地址与坐标 canonical hash 去重 |
| 街道级格式 | `<street>, <suburb>, <state code>, AU`；`matchLevel=street`，门牌、楼栋、室号为空；可唯一确定的来源邮编保留，否则留空。 |
| 街道去重 / 验证 | 国家 + 规范行政层级 + 街道名，同一路段不同坐标、邮编或来源 ID 不增加条数；行政字段不使用最近目录点推断。 |
| 同步方式 | 自动初始化一次；checkpoint 自动续跑，完整扫描或来源耗尽后停止。显式来源探测发现版本变化时才构建新快照，失败保留上一 active 快照 |
| 既有门牌来源验证 / 排除 | 州代码与 suburb 必须来自来源并通过目录核验；未知邮编须经推断唯一确定，否则不发布，独立住宅用途证据仅用于住宅子集 |
| 策略版本 / 状态 / 更新 | 1.14 / 严格住宅建筑门禁 + 多规则完成下限 + 街道契约 street-v1 + address-structure-v1 + administrative-names-v19 + 热门优先 + 州分片 / 2026-11-11 |
共用规则（翻译、发布、生成、同步框架和结构门禁）见 [README.md](README.md)；本文件只记录本国差异。

- 默认国家完成数量下限 20,000；州/领地、城市、区县单来源均衡采样上限 4,000/350/80，后台可覆盖；国家总量不是发布上限，行政区划与邮编目录保持完整。

## 既有来源街道提取（2026-09-08）

- Geofabrik `g70-streets` 提取来源命名道路及已有门牌，保留真实行政字段；道路点位于原始线几何，按国家/行政层/道路去重，不从最近目录点补行政区。街道楼栋、单元和住宅证据为空，邮编须经导入后推断唯一确定，否则不发布（2026-10-26）；非住宅门牌保留但不获得住宅用途。
- Overture `addresses-streets-residential-subset-v6` 保留来源街道和未匹配住宅建筑的真实门牌；仅实际相交且有明确住宅类别的门牌获得住宅证据，街道不得因落入建筑面而获得住宅用途。候选先去重再均衡采样；建筑分类失败保留地址事实，不伪造住宅证据。

- 单次上限（capacity-20261003）：overture（1 个分片）：单次上限 200,000；geofabrik（1 个分片）：单次上限 200,000。

- 来源缺少邮编时按顺序推断，且只在结果唯一时填写，冲突一律留空：
  1. 坐标落在且仅落在一个邮政区多边形内：澳大利亚统计局 ASGS 第 3 版 2021 邮政区（CC BY 4.0）；
  2. GeoNames 邮编目录中同一一级行政区下该城市或区县只对应一个邮编，且目录坐标在约 30 km 内（CC BY 4.0）；
  3. 同一城市约 1 km 范围内至少 3 条来源自带邮编的地址邮编一致（推断出的邮编不参与投票）。

## 目录本地名核验（2026-10-11）

- 目录本地名修正：省级 0 条、城市 491 条（已存地址由 catalog-native-addresses-v2 一次性改写）。

- 一级行政区多边形：纠正与坐标冲突或无法识别的来源区域，并排除境外坐标。

## 热门城市与热门地区优先（2026-10-19）

- Overture 导出改为热门优先配额（详见共用规则）：先统计各“一级行政区+城市”的地址数，每个城市保底 10 条，热门城市的都市圈（按名称或中心坐标半径归圈）补到每圈共 30,000 条，其余预算按目录人口平方根加权；按记录 ID 哈希切片抽样，预算增大只追加不替换。适配器修订为 `addresses-streets-residential-subset-v8-popular-ranks`（v8 起导出每行写明热门分层与排名，导入先按排名取热门都市圈配额，剩余名额再按保底、一级行政区下限和均衡规则分配，2026-10-25），所有 Overture 分片按新能力重新评估。

## 州分片扩容（2026-11-11）

- 新增来源 `overture-au-states`：同一 Overture 地址数据按州/领地拆成 8 个分片（`address_levels[1]` 取值 NSW、VIC、QLD、WA、SA、TAS、ACT、NT），字段、门禁、住宅证据和去重规则与全国分片完全一致，仅改变抽取范围；不含外部领地（OT）。
- 分片优先级/上限：NSW 1/600,000、VIC 2/500,000、QLD 3/420,000、WA 4/200,000、SA 5/150,000、TAS 6/50,000、ACT 7/40,000、NT 8/20,000，合计 1,980,000。拆分原因：导入时一个分片的全部候选在内存中排序，单分片不超过已验证的 600,000。
- 检测依据（Overture 2026-10-21.0 本地镜像）：全国 15,739,608 条，街道 100%、门牌 99.99%、邮编 99.995%；上一次全国分片严格门禁接受 380,164、拒绝 284。
- 分步导入：一次运行只增长一个步长，未到分片上限时标记 `source_growth_step`，约 1 分钟后对同一来源版本继续运行，到上限或无进展才停止。

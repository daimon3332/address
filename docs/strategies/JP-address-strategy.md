# JP 日本地址生成策略

| 项目 | 核心内容 |
|---|---|
| 主源 | 日本数字厅 Address Base Registry，经 Geolonia 月度构建的住居表示点与按市区町村的地番点；日本邮便邮编；PLATEAU/MLIT 建筑用途与轮廓；Geofabrik OSM 补充住宅轮廓。 |
| 既有门牌级格式 / 邮编 | 住居表示：`〒<postcode> <都道府県><市区町村><町名><丁目><街区符号>番<住居番号>号`；地番（住居表示未実施区域）：`〒<postcode> <都道府県><市区町村><町名>[<丁目>]<地番>番地[<支号>]`，含 `prc_num3` 的稀有地番直接淘汰。邮编只接受日本邮便 `utf_ken_all.csv` 对都道府县、市区町村、町域及丁目范围的唯一精确匹配；规范化为 `NNN-NNNN`，不按邻近点补齐。建筑名、室号缺失时保持为空。 |
| 行政区 | ABR `ja.json` 提供都道府县与市区町村；住居表示块提供町名、丁目、街区符号和住居番号。住居表示仅保留带丁目且能拆分出独立町域的记录，避免町域与街道字段重复；无丁目的地番町域只输出两级行政层级（district 置空），同样避免重复。政令指定都市按区级团体码（补前导零后取 5 位）映射到其 PLATEAU 城市包，修复了此前 exact-match 漏配导致的候选截断。；目录都道府县本地名统一为正式全称（東京都、大阪府、京都府、北海道、其余“県”），地址中的简称改回全称（administrative-names-v19） |
| 住宅子集证据 | ABR 只证明地址存在。住居表示点必须精确落入 PLATEAU `usage=residential` 建筑面，或当期 OSM 明确住宅建筑面；地番点必须恰好落入 1 个 PLATEAU 住宅建筑面且不落入任何非住宅建筑面，同一建筑含多个地番点时全部淘汰。不使用附近建筑。PLATEAU 转换包逐文件校验 SHA-256，OSM 非住宅 POI 与全局黑名单继续排除。 |
| 真实字段 / 生成字段 | ABR 的都道府县、市区町村、町名、丁目、街区/住居号或地番，日本邮便邮编及来源坐标均为真实字段；生成字段：无，建筑名和室号缺失时保持为空 |
| 坐标 / 去重 | 来源坐标统一为 WGS84；地址点必须精确落入住宅建筑面。按 ABR 稳定 ID、PLATEAU building uid 和规范化地址去重，住居表示优先于地番 |
| 街道级格式 | `<都道府県><市区町村><町域><道路>`；`matchLevel=street`，门牌、楼栋、室号为空；可唯一确定的来源邮编保留，否则留空。 |
| 街道去重 / 验证 | 国家 + 规范行政层级 + 街道名，同一路段不同坐标、邮编或来源 ID 不增加条数；行政字段不使用最近目录点推断。 |
| 同步方式 | 无。ABR 导入来源已于 2026-11-11 停用并从来源目录移除；本文件其余各行记录的是已发布地址当初的来源、字段和门禁。 |
| 既有官方住宅适配器 / 排除 | ABR 地址点必须唯一落入 PLATEAU/OSM 明确住宅建筑面，并唯一匹配日本邮便 7 位邮编；缺字段、校验失败、非住宅名称及多地番歧义记录全部淘汰。 |
| 策略版本 / 状态 / 更新 | 4.0 / 来源已停用，仅保留已发布地址，不再同步 / 2026-11-11 |
共用规则（翻译、发布、生成、同步框架和结构门禁）见 [README.md](README.md)；本文件只记录本国差异。

- 默认 active 地址及本来源上限 20,000；都道府县、市区町村、町域单来源均衡采样上限 7,000/1,000/200，后台可覆盖；最低行政节点先均衡保留 5 条，国家总量不是发布上限，行政区划与邮编目录保持完整。
- 同一源版本产生 0 条合格记录时标记 `SOURCE_QUALITY_FAILED`，只重查源版本元数据；上游版本或适配/清洗版本变化后自动重试。
- 首次严格快照只要存在合格记录即可发布；后续快照仍执行数量与行政覆盖防回退门禁，避免因总量目标阻塞真实的小规模数据。
- 地番扩展在住居表示匹配后按 PLATEAU 城市包流式执行。仅保留含登记所坐标、纯数字地番且无 `prc_num3` 的记录；地番点必须恰好落入一个住宅建筑面且不落入非住宅建筑面。以 PLATEAU building uid 去重，住居表示优先，避免同一住宅以住居表示与地番重复计数。
- 当前提取指纹的候选库和 checkpoint 会跨任务、进程与容器重启保留；来源版本或提取能力指纹变化时适配器自动替换旧状态。已完成的 PLATEAU/OSM 原始资产立即回收，PID 临时文件、下载残片和解压目录由周期清理器自动处理。

- 单次上限（capacity-20261003）：japan-abr（1 个分片）：单次上限 200,000。

- 本国邮编精细到街道或楼栋（或不使用邮编），不按区域或邻近地址推断；来源缺失时保持留空。

- 提取时限（2026-10-11）：ABR 提取进程上限由 120–140 分钟降为 90–95 分钟，超时时先保存断点，确保在 150 分钟任务上限内完成断点写入，下次运行继续；执行能力修订 japan-abr-materialize-v5 只解除该来源此前的提取失败挂起。

- 一级行政区多边形：纠正与坐标冲突或无法识别的来源区域，并排除境外坐标。

## 来源停用（2026-11-11）

- 经用户确认，`japan-abr-residential` 来源及其导出程序、适配器代码一并删除，服务器上的候选库和 checkpoint 已清除；日本不再有可执行来源。
- 已发布的 18,474 条地址（均经 PLATEAU/OSM 住宅建筑匹配和日本邮便邮编校验）继续提供，数量不再增长，也不随上游更新。
- 停用原因：导入长期停在 ABR 下载阶段（1,294 个市区町村完成、候选 2,111,712 条未发布），连续因进程无法在取消后退出而被挂起；Overture 日本地址不含邮编，不能作为替代来源。
- 恢复条件：重新引入一个带官方邮编且可稳定完成的日本地址来源，并新增对应适配器与策略版本。

# GB 英国地址生成策略

| 项目 | 核心内容 |
|---|---|
| 主源 | Geofabrik OpenStreetMap `united-kingdom`（当前批量主源） |
| 既有门牌级格式 / 邮编 | `<flat/building if present>, <house> <street>, <post town>, <postcode>, UK`；Flat 缺失保持空；Postcodes.io/ONS Postcode Directory 用于格式和坐标核验；完整物业地址不由 postcodes.io 生成。只清洗格式，不创造或按邻近地址补齐 |
| 行政区 | ONS 地区/地方政府目录作为候选核验；当前从 OSM 记录并经 catalog 反查。行政层级必须与坐标反查一致；冲突时保留源值在隔离区并拒绝发布 |
| 住宅子集证据 | OSM `building` 住宅标签或 Overture/建筑证据；仅有邮编绝不视为住宅。住宅证据必须来自明确建筑/用途字段，不能由地址存在推断 |
| 真实字段 / 生成字段 | 门牌、道路、building/flat、Post Town、postcode 和坐标来自 OSM；生成字段：无，Postcodes.io 只用于核验 |
| 坐标 / 去重 | OSM WGS84 坐标通过英国边界门禁；按 OSM ID 和规范化地址 canonical hash 去重 |
| 街道级格式 | `<street>, <town>, GB`；`matchLevel=street`，门牌、楼栋、室号为空；可唯一确定的来源邮编保留，否则留空。 |
| 街道去重 / 验证 | 国家 + 规范行政层级 + 街道名，同一路段不同坐标、邮编或来源 ID 不增加条数；行政字段不使用最近目录点推断。 |
| 同步方式 | 自动初始化一次；完整扫描或来源耗尽后停止。显式来源探测发现 Geofabrik 版本变化时才构建新快照 |
| 既有门牌来源验证 / 排除 | Postcodes.io 只核验 postcode、坐标和行政字段，不生成物业地址；缺真实道路、必填行政字段或坐标的记录拒绝发布；未知邮编须经推断唯一确定，否则不发布，住宅证据仅用于住宅子集 |
| 策略版本 / 状态 / 更新 | 1.14 / 严格住宅点面关联 + 多规则完成下限 + 街道契约 street-v1 + address-structure-v1 + administrative-names-v19 + 热门优先 + 分区上限上调 / 2026-11-11 |
共用规则（翻译、发布、生成、同步框架和结构门禁）见 [README.md](README.md)；本文件只记录本国差异。

- admin1 所属构成国与 Overture 一级行政区多边形不一致时按目录邮编改为多边形构成国内的郡/单一管理区，给不出时改为构成国；目录中 London 的上级改为 England。
- 默认国家完成数量下限 35,000；地区、邮政城市、区单来源均衡采样上限 3,000/350/80，后台可覆盖；国家总量不是发布上限，行政区划与邮编目录保持完整。

- OSM 独立地址点仅在精确落入明确住宅建筑面时获得住宅用途证据；不使用附近建筑、同街道或邻近坐标推断。

## 既有来源街道提取（2026-09-08）

- Geofabrik `g70-streets` 提取来源命名道路及已有门牌，保留真实行政字段；道路点位于原始线几何，按国家/行政层/道路去重，不从最近目录点补行政区。街道楼栋、单元和住宅证据为空，邮编须经导入后推断唯一确定，否则不发布（2026-10-26）；非住宅门牌保留但不获得住宅用途。

- 单次上限（capacity-20261003）：geofabrik（1 个分片）：单次上限 200,000。

- 本国邮编精细到街道或楼栋（或不使用邮编），不按区域或邻近地址推断；来源缺失时保持留空。

## 目录本地名核验（2026-10-11）

- 目录本地名修正：省级 4 条、城市 363 条（已存地址由 catalog-native-addresses-v2 一次性改写）。

- 来源分片（2026-10-11）：Geofabrik 英国整包（united-kingdom）在 150 分钟任务上限内无法完成，改为 England、Scotland、Wales 三个分片，北爱尔兰取 ireland-and-northern-ireland 并按英国国界裁剪；每片单次上限 200,000。旧整包数据集保留为已有证据，新分片独立记录版本、耗尽和失败状态。

- 门牌：英国房屋名（house name）是合法门牌，不降为街道级。
- 一级行政区多边形：目录层级与多边形不一致，仅排除境外坐标，不改写来源区域。

## 热门城市与热门地区优先（2026-10-19）

- Geofabrik 分区优先级/上限：England 1/250,000、Scotland 2/80,000、Wales 3/40,000、Northern Ireland 4/25,000。Geofabrik 抽样按地址密度随机分布，伦敦等大城市随总量按比例增加。

## 分区上限上调（2026-11-11）

- England 250,000 → 600,000、Northern Ireland 25,000 → 60,000；两个分片上一次导入都恰好达到旧上限（England 接受 250,000、拒绝 109,958，主要为 invalid_administrative_hierarchy），说明来源仍有余量。Scotland（73,861/80,000）和 Wales（18,700/40,000）未达上限，保持不变。
- 英国没有开放的全国地址库：Overture 地址主题不含英国，HM Land Registry 成交价数据与 EPC 数据中的地址受 Royal Mail/OS 许可限制，OS Places 需付费，故仍只使用 OSM。实际可发布数量以导入结果为准。
- 分步导入规则同共用规则：未到分片上限时以 `source_growth_step` 对同一来源版本继续运行。
